# Changelog

## [0.1.0] - 2026-10-05
First version for keypad phones, based on Fossify Clock 1.6.0.

### Added
- Home list (Clock, Alarm, Stopwatch, Timer, Settings) instead of bottom tabs, keys 1–5 open the screens
- Keypad control everywhere: focus highlight, Menu key actions, "+" rows instead of floating buttons
- Time picker for keys: typed digits, Cancel / Save rows
- On / off switch with an arrow for alarms and timers, "Repeat" checklist of days
- Ringing alarm screen for keys (← / OK snooze, → dismiss), opened on an unlocked DumberOS phone too
- The phone's own time zone on the Clock screen
- About screen with the keypad shortcuts, purple app icon

### Fixed
- Crashes of the alarm list and alarm editor with newer Kotlin versions
